# Capítulo 4 - Java Virtual Machine (JVM)

## Tema

Java Virtual Machine (JVM).

## Contenido

Se explica qué es la JVM y cuál es su función dentro del ecosistema Java.

La JVM permite ejecutar el bytecode generado al compilar programas Java y facilita que el código pueda ejecutarse en diferentes sistemas operativos.
