# Capítulo 7 - Versiones de Java

## Tema

Evolución de las versiones de Java.

## Contenido

Se explica la evolución de Java a través de sus diferentes versiones.

También se introduce la importancia de conocer la versión de Java utilizada para desarrollar y ejecutar programas.

## Código

Este capítulo es principalmente teórico y no contiene ejercicios de código.
