# Capítulo 10 - IDE IntelliJ IDEA

## Tema

Introducción al entorno de desarrollo IntelliJ IDEA.

## Contenido

Se presenta IntelliJ IDEA como entorno de desarrollo integrado (IDE) para trabajar con Java.

Se explican aspectos básicos del entorno y su utilidad para crear y ejecutar proyectos Java.

## Código

Este capítulo se centra principalmente en conocer y configurar el entorno de desarrollo.
