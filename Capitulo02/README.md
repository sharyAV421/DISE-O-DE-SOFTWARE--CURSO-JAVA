# Capítulo 2 - Contexto

## Tema

Contexto de Java y su importancia en el desarrollo de software.

## Contenido

En este capítulo se presenta el contexto en el que surge Java y su relación con el desarrollo de aplicaciones.

Se introduce la importancia de conocer los fundamentos del lenguaje antes de comenzar a programar.

## Código

Este capítulo es principalmente teórico y no contiene ejercicios de código.
