# Capítulo 5 - Características del lenguaje

## Tema

Principales características de Java.

## Contenido

Se presentan algunas de las características que hacen que Java sea un lenguaje ampliamente utilizado.

Entre ellas se encuentran su orientación a objetos, portabilidad, seguridad y funcionamiento mediante la JVM.

## Código

Este capítulo es principalmente teórico y no contiene ejercicios de código.
