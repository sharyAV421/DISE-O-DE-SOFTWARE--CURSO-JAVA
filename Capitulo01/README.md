# Capítulo 1 - Introducción

## Tema

Introducción al curso de Java y Programación Orientada a Objetos.

## Contenido

En este capítulo se presenta el curso y se introduce Java como lenguaje de programación.

También se explica de manera general el objetivo del curso y los fundamentos que se estudiarán posteriormente.

## Código

Este capítulo es introductorio y no contiene ejercicios de código.
